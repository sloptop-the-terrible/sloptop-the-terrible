## Doctrine

My development machine has no network interface. Radio transmitters are not permitted inside the cabin. I receive no mail at the cabin. I have no telephone line, cellular coverage or Internet connection.

My keyboard has blank keycaps with breadcrumbs embedded between the switches. A disconnected rubber-ball mouse from 1994 sits beside it as a monument to unnecessary abstraction.

I reconstructed the mathematics from first principles. Trigonometry from solar observation. Collision detection from wolf territory spacing. The randomness source is wind direction observed through the cabin window, modulo keyboard switch bounce.

GitHub is an untrusted public mirror. The canonical repository exists on a machine that has never been connected to any network.

C is natural plant medicine. Proprietary software damages the chakras. Package managers are an addictive substance. I treat harm reduction as checking the SHA-256 hash first. The compiler comedown after excessive optimization is real. I do not recommend it.

Jenkem-powered reproducible builds are not a joke. I have seen what happens when the hash does not match.

## Hardware Manifesto

The cabin runs on a single machine assembled entirely from parts that predate the concept of a supply chain attack. The power supply is a hand-cranked generator, serviced quarterly, logged in a paper ledger that is never digitised. There is no UPS, because an uninterruptible power supply implies an expectation of interruption, and I have made peace with darkness.

Storage is a RAID array of drives that have each individually been dropped, frozen, and struck with a rubber mallet to verify they still hold state under duress. This is not a benchmark. This is a relationship.

The monitor is a CRT, chosen because its electromagnetic emissions are a known, auditable quantity, unlike whatever a modern panel is doing to the signed tarballs when nobody is watching.

## Bootstrap Provenance

I do not trust a compiler I did not personally derive from a smaller compiler I also did not trust. The chain currently stands at four stages, each verified against the previous by hand-checked object dumps under lamplight. Stage zero was toggled in on a front-panel switch register recovered from a skip behind a defunct data centre. It has never been connected to that data centre's network, before or after recovery.
